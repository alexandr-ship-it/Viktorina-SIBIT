# СИБИТ Квиз

Живые викторины для пар и мероприятий. Ведущий выводит экран на проектор, игроки сканируют QR-код и отвечают с телефонов. На большом экране в реальном времени обновляется таблица лидеров.

## Что умеет

- **Конструктор викторин.** Вопросы с одним или несколькими верными ответами, от 2 до 6 вариантов, таймер от 5 до 120 секунд, очки (0 / 500 / 1000 / 2000), картинка по ссылке.
- **Вставка списком.** Вопросы можно вставить текстом: варианты с `+` верные, с `-` неверные.
- **Вход по QR или по коду.** Игроки не регистрируются, достаточно имени.
- **Свой темп.** Каждый отвечает со своей скоростью. Вопросы можно перемешать, чтобы порядок у всех был разный.
- **Очки.** От 50% до 100% за верный ответ в зависимости от скорости, плюс бонус за серию верных ответов подряд.
- **Экран ведущего.** Таблица лидеров с анимацией, цветные точки по каждому вопросу, общая точность, QR для опоздавших.
- **Итоги.** Пьедестал, таблица участников, статистика по каждому вопросу, выгрузка результатов в CSV (открывается в Excel).
- **Надёжность.** Если у игрока пропал интернет или он обновил страницу, он вернётся в игру с теми же очками. Верные ответы проверяет сервер и не отправляет на телефоны заранее.
- **Музыка и звуки.** На большом экране играет фоновая музыка в лобби и во время игры. Эффекты звучат, когда игрок заходит, на старте, при смене лидера, на барабанной дроби и фанфарах перед пьедесталом. На телефонах только короткие эффекты: верно, неверно, тиканье последних 5 секунд, серия, финал. Всё синтезируется в браузере, аудиофайлов и авторских прав нет.
- **Импорт и экспорт.** Каждую викторину можно скачать файлом и загрузить обратно.

## Запуск на своём компьютере (5 минут)

Нужен Node.js версии 18 или новее: https://nodejs.org

```bash
cd sibit-quiz
npm install
npm start
```

Открой http://localhost:3000. Телефоны должны быть в **той же Wi-Fi сети**, что и компьютер. QR-код на экране ведущего сам подставит локальный адрес компьютера вместо `localhost`.

> Если телефоны не подключаются, скорее всего, порт 3000 блокирует брандмауэр Windows. Разреши Node.js доступ к частной сети, когда Windows спросит. В гостевых Wi-Fi сетях устройства часто изолированы друг от друга, тогда нужен вариант с хостингом.

## Выложить в интернет (бесплатно, Render)

1. Залей папку проекта в репозиторий на GitHub.
2. На https://render.com нажми **New → Blueprint** и выбери репозиторий. Render прочитает файл `render.yaml`.
3. Задай `ADMIN_PASSWORD`. Это пароль ведущего, без него любой сможет создавать и удалять викторины.
4. Через пару минут сайт будет доступен по адресу `https://sibit-quiz-xxxx.onrender.com`.

Ограничения бесплатного тарифа:
- Сервер засыпает после 15 минут без посетителей. Первое открытие после этого занимает около минуты, поэтому открой сайт заранее, до начала пары.
- **Викторины не сохраняются между перезапусками.** Перед закрытием вкладки скачай викторину кнопкой «⋯ → Скачать файлом», а потом загрузи через «Импорт из файла». Для постоянного хранения подключи диск (платный тариф) и укажи `DATA_DIR=/var/data`.

## Свой сервер (VPS, например в России)

```bash
npm install --omit=dev
ADMIN_PASSWORD=секрет PORT=3000 npm start
```

Для постоянной работы используй `pm2` или systemd. Если сайт стоит за nginx с доменом, пробрось WebSocket (`proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade";`) и укажи `PUBLIC_URL=https://quiz.твой-домен.ru`, чтобы QR-код вёл на правильный адрес.

## Настройки (переменные окружения)

| Переменная | Что делает |
|---|---|
| `PORT` | Порт сервера, по умолчанию 3000 |
| `ADMIN_PASSWORD` | Пароль ведущего. Если не задан, вход ведущего открыт всем |
| `PUBLIC_URL` | Адрес сайта для QR-кода, если он стоит за прокси |
| `DATA_DIR` | Папка для хранения викторин, по умолчанию `./data` |

## Как провести игру

1. **Мои викторины → Запустить.** Выбери настройки и открой комнату.
2. Выведи экран ведущего на проектор, кнопка «На весь экран».
3. Игроки сканируют QR-код или открывают адрес и вводят 6-значный код.
4. Нажми **«Начать игру»** и смотри таблицу лидеров.
5. Когда все закончат, нажми **«Завершить игру»**. Появятся пьедестал и итоги, их можно скачать.

**Про звук.** Браузер не включает звук без клика, поэтому на экране ведущего нажми «🔈 Включить звук» или кликни в любом месте. Кнопки «🎵 Музыка» и «🔊 Звуки» включают и выключают их по отдельности, выбор запоминается. На телефоне звук выключается кнопкой 🔊 в правом верхнем углу. На iPhone звука не будет, если включён беззвучный режим.

Одна игра выдерживает до 300 игроков.

## Структура

```
server.js            сервер: викторины, игры, подсчёт очков
sample-quizzes.json  викторина-пример, загружается при первом запуске
public/
  index.html         мои викторины
  edit.html          редактор викторины
  host.html          экран ведущего: QR, лобби, лидерборд, итоги
  play.html          экран игрока на телефоне
  style.css          фирменный стиль СИБИТ
  sound.js           музыка и звуковые эффекты (Web Audio)
test/game.test.js    автотест полной игры
```
